see the latest [implementation receipt](../implementation-status.md).

builds, format/lint/type checks, synthetic offline tests, exact wheel installation,
nonroot stdio smoke, archive audits and a checksummed local image/package bundle.

a failure must not produce a success receipt. Dirty source is explicitly recorded.
CI repeats verification without customer secrets or publication. A local run is
not a remote CI result. Native ARM64 and AMD64 are verified separately; see the
[AMD64 deployment receipt](evidence/2026-11-12-server-deployment.json).
